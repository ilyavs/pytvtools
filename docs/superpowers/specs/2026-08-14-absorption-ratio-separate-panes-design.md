# Absorption Ratio Demo — Separate AR Panes + Paper-Matched Weighting

Date: 2026-08-14
Status: Approved design (pending implementation)

## Background

The absorption-ratio demo page (`demos/absorption_ratio.html`, generated by
`notebooks/absorption_ratio.py`) currently shows S&P 500 candles and a single AR
pane holding two series on one axis — AR daily (`s1_0`) and AR weekly (`s1_1`) —
with a single ATL (all-time-low) price line on the weekly series.

Adversarial review against the authoritative source (Kritzman, Li, Page & Rigobon,
"Principal Components as a Measure of Systemic Risk", JPM 2011) surfaced two gaps:

1. The paper estimates the covariance with **exponential weighting** whose
   half-life equals half the window (250 days for the 500-day window); the demo
   used equal-weighted `np.cov` and disclosed the deviation in the page text.
2. Both AR series share one pane and one ATL line.

## Goals

- Match the paper's covariance estimator (exponential weighting, half-life =
  window/2) in `pytvtools_core.measures` and the notebook.
- Render AR daily and AR weekly in **separate panes**, each with **its own ATL
  line** and legend.
- Keep the page text truthful: no "equal weighting" disclaimer; instead state
  the paper-matching estimator, and note the separate-pane/ATL layout.

## Non-goals

- Regenerating the embedded HTML data locally (reads Databricks UC table
  `workspace.chartdata.ohlcv`). Data refresh happens on the next Databricks
  backfill run.
- Publishing to the core repo until that re-run lands (exponential weighting
  changes every AR value + ATL).

## Changes

### 1. `src/pytvtools_core/measures.py`

- Add `_ewma_cov(returns, half_life)` — exponentially-weighted covariance:
  weights `0.5 ** (age / half_life)`, normalized to sum 1, biased estimator.
- `absorption_ratio(returns, n_eigenvectors=1, half_life=None)` — `half_life`
  selects EWMA covariance; `None` keeps equal-weighted `np.cov` (back-compat).
- `rolling_absorption_ratio(..., half_life=None)` — forwards `half_life`.

### 2. `tests/test_measures.py`

New tests (TDD, red→green):
- EWMA output matches a hand-computed exponentially-weighted eigendecomposition.
- A very long half-life (`1e6`) ≈ equal-weighted (`np.cov`) within `1e-4`.
- A recent correlation spike raises AR more under a short half-life than under
  equal weighting.
- `rolling_absorption_ratio` accepts `half_life` and stays within `[0, 1]`.

### 3. `notebooks/absorption_ratio.py`

- Backfill: pass `half_life=daily_window / 2` and `half_life=weekly_window / 2`.
- `atl_daily_by_key` + `atl_weekly_by_key` (per param key, per series).
- JS template: 3 panes —
  - `chart0` SPX candles (360px), legend `l0`
  - `chart1` AR daily (200px), legend `l1`
  - `chart2` AR weekly (200px), legend `l2`
- `s1_1` (weekly) moves to `chart2`; both AR panes use the fixed 0–1 axis.
- Two ATL maps + two price lines (`atlLineDaily` on `s1_0`, `atlLineWeekly` on
  `s1_1`), updated in `applyParam` per selected param key.
- Time-scale sync array `[chart0, chart1, chart2]`.
- Pane map `{0:[cs0], 1:[s1_0], 2:[s1_1]}`; `setupLegend(2)`; legend-value
  update loop touches `l1` + `l2`.
- Text: replace the equal-weighting disclaimer with the paper-matching
  statement; note separate panes with per-pane ATL lines.

### 4. `demos/absorption_ratio.html`

Mirror of the notebook template changes (current embedded data) so the page
remains previewable. Not pushed to core until data re-run.
